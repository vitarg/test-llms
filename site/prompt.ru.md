Создай небольшое приложение на React + TypeScript для учёта личных расходов.

Структура:

- components/
- hooks/
- types/
- utils/

Возможности:

- Добавление расхода
- Удаление расхода
- Подсчёт общей суммы расходов
- Фильтрация по категории
- Сохранение данных в localStorage

Требования:

- Сначала покажи структуру папок.
- Затем сгенерируй все файлы.
- Используй корректные типы TypeScript.
- Избегай дублирования кода.
- Объясни компромиссы и возможные будущие улучшения.
